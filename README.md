# 99Exchange

## Overview
99Exchange is a static, Tailwind CSS–powered landing page for a cryptocurrency exchange concept. The UI showcases navigation, a hero section with reserves, and a simple currency conversion widget.

This repository contains:
- `index.html`: The page markup and a small JavaScript snippet for on-page conversion.
- `src/styles.css`: Tailwind entry file that imports base, components, and utilities.
- `public/styles.css`: Compiled CSS output (generated by the build script).
- `tailwind.config.js`: Custom theme extension (colors and font family).
- `tailwind-default.config.js`: A reference Tailwind configuration with default tokens for documentation purposes.
- `package.json`: Build script and dependency (`tailwindcss`).

## Public Surface Area

### HTML Components (in `index.html`)
- **Header / Navbar**: Top navigation with brand, links, contact, and login CTA.
  - Classes use Tailwind utilities and custom theme colors (e.g., `bg-final`, `border-secondary`).
- **Hero + Reserves Panel**: Two-column layout with a background image and a reserves list (BTC, ETH, USDT-TRC20) demonstrating typography and layout utilities.
- **Exchange Widget**: A three-column section allowing users to input "Get" amount (crypto) and "Pay" amount (USD) with a displayed rate.

### JavaScript Functions (in `index.html`)
Two event handlers implement the conversion logic using a fixed rate (1 BTC = 47,943.45 USD):

```html
<script>
  document.querySelector("#input1").addEventListener('keyup', function(){
    var input = parseInt(this.value);
    var output = input * 47943.45
    if (input){
      document.querySelector("#input2").value = output
    } else {
      document.querySelector("#input2").value = ''
    }
  })

  document.querySelector("#input2").addEventListener('keyup', function(){
    var input = parseInt(this.value);
    var output = input / 47943.45
    if (input){
      document.querySelector("#input1").value = output
    } else {
      document.querySelector("#input1").value = ''
    }
  })
</script>
```

#### Usage Notes
- **Data type**: `parseInt` is used; decimal amounts will be truncated. Consider `parseFloat` for production.
- **Rate source**: The rate is hardcoded. Replace with a live API for real conversions.
- **Validation**: No input validation or formatting is applied; add as needed.

## Installation and Build

### Prerequisites
- Node.js (LTS)

### Install Dependencies
```bash
npm install
```

### Build CSS
Generates `public/styles.css` from `src/styles.css` using Tailwind.
```bash
npm run build
```

The script runs:
```bash
tailwindcss build -i src/styles.css -o public/styles.css
```

## Run Locally
Open `index.html` in your browser after building CSS. For a simple static server:
```bash
npx serve .
```
Then navigate to the served URL and interact with the exchange widget.

## Usage Examples

### 1) Update the Conversion Rate
Replace the hardcoded USD rate in both handlers:
```html
var output = input * 50000 // example new USD rate
// ... and ...
var output = input / 50000
```

### 2) Use Decimals and Format Output
```html
var input = parseFloat(this.value)
var output = (input * 47943.45).toFixed(2)
```

### 3) Fetch Live Rates
```html
async function fetchRate(){
  const res = await fetch('https://api.example.com/rate?pair=BTCUSD')
  const { rate } = await res.json()
  return rate
}
```
Use the fetched `rate` in the handlers instead of the hardcoded constant.

## Architectural Notes
- The project is intentionally simple and framework-free for clarity.
- Tailwind classes drive layout and design; update `tailwind.config.js` to evolve brand tokens.
- `tailwind-default.config.js` is a non-production reference of default Tailwind tokens to help discover available utilities.
